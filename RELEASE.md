# 0.3.2-public — experimental pre-release

- Interactive Launchpad Pro MK3 lightshows with layered keyboard overlays and neon pad effects.
- Auto Party, live colour selection, playable FM-1 synthesis and a browser companion.
- Persistent custom scene-bank upload/readback protocol.
- Approved LAUNCHPARTY logo and animated boot presentation.
- Product identity `FM-1_900`; Felucca update-loader packaging.

Prepared binary: `launchparty-0.3.2-public.fwsc`.

SHA-256: `83b4a2ee4aa539c8946e8b9660a51b0bc6eff5abd1677fab0f3b55712429873e`.

This is a test release. The preceding 0.3.1 development version had documented device version reporting and preserved scene data; this 0.3.2 public build has not been installed on hardware, but a complete physical performance, audio-load and external USB-host compatibility review is outstanding. Other Launchpad models are not supported by this release claim.

The proposed GitHub publication must not include private device backups, Joomla configuration, gallery submissions, personal operator logs or the uncurated Ableton archive.
